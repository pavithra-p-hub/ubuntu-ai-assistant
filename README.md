# Ubuntu AI Assistant 🤖

An AI-powered Linux system assistant built using Python, Django, and Ollama.

## Features

- 🕐 Current time
- 💻 System status
- 🖥️ System information
- 🔋 Battery status
- 🌐 Wi-Fi status
- 🌍 Internet status
- 💾 Disk space information
- ⚙️ Running processes
- 📁 List files
- 🔍 Search files
- 🌐 Open websites
- 🤖 AI-powered responses using Ollama and Qwen

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- Ollama
- Qwen 2.5
- psutil
- Git & GitHub

## How to Run

```bash
source venv/bin/activate
python3 manage.py runserver
